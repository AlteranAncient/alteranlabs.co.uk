I've been into computers for as long as I can remember. I was formatting and reinstalling operating systems by the age of eight, and that curiosity carried me through an A-Level and a Computer Science degree. These days I work across the full stack: front-end, back-end and DevOps.

## About "Alteran Labs"

Alteran Labs started life as a small, Stargate-themed forum for friends and fans. It was one of my first ventures into hosting and webmastering, and my first PHP and MySQL project. The community is long gone, but the name stuck, so the domain is now home to my personal site.

## What I work with

**Front-end:** HTML, CSS and Sass, and JavaScript. I prototype in code rather than in design tools.

**Back-end:** PHP (I'm a Zend Certified PHP Engineer, and it's the language I've used longest), Go for micro-services, MySQL and Node.js.

**Ops:** AWS, Docker and Vagrant, Nginx, Git (yes, including `git bisect`), Bash and Active Directory.

**Tools I like:** Laravel, Bootstrap and Semantic UI for quick UI work, and PhpStorm.
